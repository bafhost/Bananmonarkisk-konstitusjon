# Beslutningsprotokoller

Ingen formelle grunnlovsvedtak eller signerte protokoller er registrert.

Ved fremtidige vedtak lagres én protokoll per møte/avgjørelse, med:
- protokoll-ID og dokumentdato
- beslutningstakere og hjemmel for kompetansen
- referanse til eksakt versjon og SHA-256
- ordlyd og stemmetall
- eventuelle merknader/habilitet
- autentisering og etterprøvbar signatur

En chatmelding eller en GitHub-merge er ikke tilstrekkelig som beslutningsprotokoll.
